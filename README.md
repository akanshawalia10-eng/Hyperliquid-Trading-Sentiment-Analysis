# Hyperliquid Trading Sentiment Analysis

## Overview
This project explores the relationship between Bitcoin market sentiment and Hyperliquid trader performance using the Bitcoin Fear & Greed Index. The analysis includes data preprocessing, exploratory data analysis, and visualization to identify patterns and profitability trends.

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Insights
- Extreme Greed showed the highest average Closed PnL.
- Buy and Sell trades were nearly equally distributed.
- BTC was the most traded cryptocurrency.
- Trading activity increased during stronger market sentiment.
